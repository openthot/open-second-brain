System Architecture & Relational Graph

The workspace divides information into four actionability tiers. Every actionable item (Task) rolls up to a defined outcome (Project), which in turn feeds an ongoing standard (Area).

Database Definition Key Properties Connected Relations
DB_Projects Finite outcomes with fixed deadlines Status, Deadline, Progress Bar, Health Tasks (1:N), Area (N:1), Notes (1:N)
DB_Areas Ongoing spheres of responsibility Category, Status, Active Projects Count Projects (1:N), Tasks (1:N), Resources (1:N)
DB_Tasks Atomic execution steps Due Date, Priority, Eisenhower Quadrant Project (N:1), Area (N:1), Sub-tasks
DB_Notes Quick capture inbox & literature notes Status (Inbox/Processed), Type, URL Project (N:1), Resource (N:1)
DB_Resources Evergreen reference vault & guides Topic, Category, Note Count Notes (1:N), Projects (M:N), Area (N:1)
DB_Reviews Weekly & monthly reflection loops Cadence, Date, Key Wins, Friction Projects Reviewed (1:N)

Notion Formulas 2.0 Reference & Live Simulator

Test formula expressions below. Sliders simulate linked task properties to demonstrate how Notion's runtime evaluates expressions.

Live Simulator: Progress Bar & Health Engine
Formula Output [Progress Bar]: ▓▓▓▓▓▓░░░░ 60% (6/10)
Formula Output [Health Status]: 🟢 On Track

1. Visual Progress Bar (`DB_Projects`)

let(
  total, prop("Tasks").length(),
  done, prop("Tasks").filter(current.prop("Status") == "Done").length(),
  percent, if(total > 0, round(done / total * 100), 0),
  barLength, 10,
  filled, min(barLength, max(0, round(percent / 10))),
  empty, max(0, barLength - filled),
  if(
    total == 0,
    "⚪ No Tasks Assigned",
    repeat("▓", filled) + repeat("░", empty) + " " + percent + "% (" + done + "/" + total + ")"
  )
)

2. Project Health Score (`DB_Projects`)

let(
  total, prop("Tasks").length(),
  done, prop("Tasks").filter(current.prop("Status") == "Done").length(),
  isDone, prop("Status") == "Completed" or (total > 0 and done == total),
  deadline, prop("Deadline"),
  ifs(
    isDone, "✅ Completed",
    empty(deadline), "⚪ No Deadline",
    let(
      daysRemaining, dateBetween(deadline, now(), "days"),
      ifs(
        daysRemaining < 0, "🔴 Overdue by " + abs(daysRemaining) + "d",
        daysRemaining <= 3, "🟡 Due Soon (" + daysRemaining + "d left)",
        "🟢 On Track"
      )
    )
  )
)

3. Task Urgency & Overdue Badge (`DB_Tasks`)

let(
  isCompleted, prop("Status") == "Done",
  due, prop("Due Date"),
  ifs(
    isCompleted, "✓ Done",
    empty(due), "🗓️ Unscheduled",
    let(
      diff, dateBetween(due, now(), "days"),
      ifs(
        diff < 0, "⚠️ Overdue (" + abs(diff) + "d ago)",
        diff == 0, "🔥 Due Today",
        diff == 1, "⚡ Tomorrow",
        "📅 " + formatDate(due, "MMM DD")
      )
    )
  )
)

4. Eisenhower Matrix Priority (`DB_Tasks`)

let(
  u, prop("Urgency") == "Urgent",
  i, prop("Importance") == "Important",
  ifs(
    u and i, "🔥 Q1: Do First (Urgent & Important)",
    not(u) and i, "🎯 Q2: Schedule (Important, Not Urgent)",
    u and not(i), "👥 Q3: Delegate (Urgent, Not Important)",
    "🗑️ Q4: Eliminate (Neither)"
  )
)

Frequently Asked Questions

Is OpenSecondBrain really free?

Yes! OpenSecondBrain is 100% open source and free forever. Both the manual Notion setup and automated provisioner can be used without paid subscriptions or proprietary widgets.

How do I add this template to the Notion Marketplace?

Publish your parent page to the web with "Allow duplicate as template" enabled, then navigate to notion.so/templates/submit and paste your public link along with the listing description provided in docs/NOTION_MARKETPLACE_LISTING.md.

What makes Notion Formulas 2.0 better for this template?

Formulas 2.0 introduces native multi-line functions (let, ifs), array methods (map, filter), and string manipulation (repeat). This allows real-time ASCII progress bars and health assessments without relying on external, slow third-party embed widgets.
